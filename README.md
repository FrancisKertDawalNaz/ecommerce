# 🛍️ ShopMate - Modern E-Commerce Site

ShopMate is a sleek, responsive e-commerce web interface built with **Bootstrap 5**. It offers a user-friendly shopping experience with a modern UI and interactive modals for **login** and **payment selection**.

## ✨ Features

- 🚀 Responsive design for desktop and mobile
- 👤 Modal-based **Login** form for user authentication
- 🛒 Interactive **"Add to Cart"** buttons that trigger a **Payment Method** modal
- 💳 Multiple payment options: Credit Card, PayPal, and Cash on Delivery
- 🖼️ Dynamic product grid with images and pricing

## 📦 Technologies Used
